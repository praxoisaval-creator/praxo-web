# ❤️ Día Mundial del Corazón 2026 | PRAXO LTDA.

Artefacto web interactivo e inmersivo desarrollado para la campaña de salud cardiovascular y Sistema de Gestión SST de **PRAXO LTDA.**

![Logo PRAXO LTDA.](assets/logo-praxo.png)

## 🌟 Características Principales
- **Fisiología en Tiempo Real:** Monitor ECG con trazado dinámico y sonido *lub-dub* sincronizado (72 BPM y 100 BPM).
- **Simulador de Emergencia:** Protocolo de paro cardíaco asistólico y reanimación mediante desfibrilador (DEA).
- **Corazón Anatómico Reactivo:** Nodos SVG interactivos para los 5 pilares del cuidado (Movilidad, Nutrición, Descanso, Cifras de Tensión y Cero Tabaco).
- **Asistente Virtual Cardi-Bot:** Recorrido guiado paso a paso con lectura adaptativa.
- **5 Latidos por tu Salud & Autoevaluación Consciente:** Módulo reflexivo de 6 preguntas pedagógicas de prevención.
- **Gestión SST PRAXONET:** Enlace y consolidación con la plantilla oficial del sistema cloud SST.
